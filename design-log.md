**What changed:** A rapid sequence: (1) rounded-square dashboard action buttons instead of the circle+label pattern; (2) outline icons added to every nav item (Dashboard/Jobs/Clients/Invoices/Settings), matching the reference sidebars which all had icons; (3) more horizontal padding on status badges ("bubbles"); (4) hover and active button states needed to look distinct from each other, not just from the default state; (5) a real layout bug — the invoice editor's footer visually overlapped the Client card instead of sitting cleanly below it; (6) correction that the footer should NOT be pinned — it should scroll away naturally and only appear once the user scrolls to the end; (7) correction that the "mobile preview" feature built earlier was solving the wrong problem — the user wanted the pre-existing form/PDF-preview toggle (which already existed in this codebase, gated to narrow screens only) relocated to the header, not a phone-frame simulation; (8) **the invoice template's fonts had visibly changed**, which should never happen; (9) a client-picker dropdown so users can autofill the invoice's Client section from a saved client instead of typing from scratch every time; (10) email validation, which turned out to already exist on the invoice form but not on the Clients page's own form.
